# Retail Sales Analysis Using NumPy

A supermarket sales analysis project using NumPy to clean, process and analyse 28 days of sales data across five departments.

### Analysis & Features
- Inspect sales data and calculate department-wise totals.
- Identify and handle missing and invalid values.
- Perform weekly and daily sales analysis.
- Compare weekday and weekend performance.
- Calculate department-wise percentage growth.
- Identify the busiest sales days.
- Evaluate weekly sales targets.
- Rank departments based on total sales.
- Generate a formatted sales performance report.

### Technologies
- Python 3
- NumPy
- Jupyter Notebook

### Concepts Practised
NumPy arrays, indexing, reshaping, aggregation, axis operations, missing value handling, boolean masking, broadcasting, sorting and statistical calculations.

### Project Structure
- `Harisanker_FreshMart_CaseStudy.ipynb` – Complete sales analysis tasks, implementations and expected outputs.

### Run
Open the notebook using Jupyter Notebook, JupyterLab or Google Colab and execute the cells sequentially.
